# Replication Project: Racial Signals in Names and Callback Rates

## Deliverables

This project includes the following key deliverables (located in the root directory):

1. **`Replication Memo_Racial Signals in Names and Callback Rates.pdf`**: The full replication report detailing the main results, heterogeneity analysis, and deviations from the original study.
2. **`Reproducibility Statement.pdf`**: A statement documenting the software, data sources, transformations, and AI tool usage.

## How to Run

To reproduce the results from a clean state, please open **`Replication_Callback/replication.do`** and run the entire script.
This is the entry-point script that will process the raw data, run all regressions, and generate all output tables in the `output/` folder.
